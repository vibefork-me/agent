# Bootstrap installers

`generate-installers.py` renders the Windows and Unix bootstrap scripts from a release directory. The generated scripts contain SHA-256 pins for the included platform binaries and fetch only those pinned assets. The published installer script and its embedded pins are delivered over HTTPS; the script never executes an asset until its bytes match the embedded pin. The scripts use PowerShell 5.1 built-in hashing on Windows and `sha256sum` or `shasum` on Unix. The installed agent continues to verify signed manifests for later updates.

The installers speak every interface language of the agent. Their messages are the `install-*` messages of the agent's string catalog (`crates/vf-core/locales/<lang>.ftl`): one line each, with plain `{ $name }` variables only. The catalog tests require every language to have every message; `generate-installers.py --check` (part of `cargo xtask ci`) requires every message to keep the English variables, every message a template uses to exist and every installer message to be used. The language is chosen as the agent chooses it: the first set variable of `VF_LANG`, `LC_ALL`, `LC_MESSAGES`, `LANG`; otherwise the Windows display language (`GetUserDefaultUILanguage`) or, on macOS, the first preferred language that is not English; English when none is known. Spanish of Spain is used for Spain only, Latin American Spanish for any other Spanish. `install.ps1` is ASCII (other letters are `\uXXXX` escapes), so Windows PowerShell 5.1 and PowerShell 7 read it the same whatever the code page; `install.sh` is UTF-8 with LF line ends.
